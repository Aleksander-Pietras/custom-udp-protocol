# custom udp protocol

## What it is?

A Python application that simulates packet transport protocols like TCP. 

Building on UDP, the custom transport protocol’s core features are:
* Packet Ordering
* Intergrity Checksum
* Encryption and Authentication
* Basic Realiability
* Duplicate Detection
* Session Identifier

## Why?

I am making this project for education purposes for myself, to learn more about networking, how protocols handle packets and client-server interactions.
